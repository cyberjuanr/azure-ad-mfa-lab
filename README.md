# Azure AD MFA Lab

Hands-on Azure AD, MFA, Conditional Access, and VM security configuration lab.

## Azure Security & Identity Lab Overview
Configured Azure AD identities, MFA, Conditional Access, and VM NSG rules to enforce least privilege and enhance cloud security posture.

---

## Skills Demonstrated
- Azure AD Identity Management  
- RBAC (Role-Based Access Control)  
- MFA & Conditional Access  
- Network Security Groups (NSGs)  
- Azure VM deployment  
- Zero Trust principles  
- Cloud IAM  
- Cloud logging / monitoring fundamentals  

---

## Lab Objectives
1. Create Azure Free Account  
2. Create Azure AD Users & Groups  
3. Assign Least Privilege Roles  
4. Configure MFA  
5. Configure Conditional Access  
6. Deploy an Azure VM  
7. Apply NSG inbound/outbound rules  
8. Validate secure remote access  
9. Document results + screenshots
